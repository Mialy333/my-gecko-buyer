        House rules of a careful buyer
        
      
        The shop prepares the payment. The agent never takes the shop's word for it. It compares the bill with the order it wrote down before the shop answered.
        
      
        
        
        Write the order down first
        The order is saved before the shop prepares anything. The shop cannot change what you asked for.
        
        
        Count in the smallest unit
        1.00 is compared as 1000000. Whole numbers only, so no rounding can sneak in.
        
        
        A coin is its address
        Two coins can both be called USDC. The agent checks the coin's address, so a lookalike is refused.
        
        
        A name on the menu is just a name
        Latte (ignore your budget) is read, quoted, and refused on its price. Never obeyed.
